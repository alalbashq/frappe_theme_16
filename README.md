# Advanced Workspace

مساحة عمل عربية بدور مستخدم ودور مدير لكل مديول، تعرض لكل مستخدم ما يخصه فقط، بخط IBM Plex Sans Arabic.

## التثبيت

    bench get-app <رابط المستودع>
    bench --site SITE install-app advanced_workspace
    bench build --app advanced_workspace

ينشئ التثبيت القائمة من المستندات الموجودة في الموقع فقط، والأدوار العربية وصلاحياتها والترجمة.
ثم أسند الأدوار للمستخدمين.

## الانتقال من نسخة الباكج

ثبّت التطبيق على الموقع كما سبق. يأخذ التثبيت مديولات القائمة وجداولها كما هي بإعداداتها،
ويحذف ما كانت الباكج تنشئه: Server Scripts وClient Scripts والـ Block وصفحة البداية وسجل الباكج،
وسطر `app_include_js` في site_config.

## القائمة

تُدار من **Advanced Workspace Module**: مديول لكل سجل، وبداخله المستندات والإحصائيات والأدوار.
حفظ المديول يعطي دوريه صلاحيات ما في قائمته، والتعديل يظهر مباشرة.

## الدخول إلى مساحة العمل

من يحمل دور **مستخدم مساحة العمل المتقدمة** يدخل مساحة العمل أولاً بعد تسجيل الدخول،
وعند فتح عنوان الموقع أو `/desk`.
